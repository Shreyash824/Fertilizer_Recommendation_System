# Fertilizer Recommendation System

An AI-powered fertilizer recommendation web app that helps farmers choose the right fertilizer — the right **bags, at the right stage, for their land** — based on soil colour, soil type, crop, and growth stage.

Built with **Flask + Random Forest** and a rule-based agronomy engine grounded in the BHU Fertilizer Manual.

## Features

- **Soil colour → soil test suggestion** — picks the most relevant lab tests (pH, EC, Zn, OC…) based on soil colour, with priority and reasoning
- **N/P/K estimation** — missing nutrient values are estimated from soil colour/type and clearly badged as *estimated*
- **Bag recommendation with price** — fertilizer name, bags per acre, total bags, and ₹ cost for the farmer's land size
- **Combination recommendation** — primary grade + **Urea** (when N is short) + **MOP** (when K is short)
- **Alternatives** — other usable fertilizers with grade and per-bag price
- **Soil health alerts** — Zn deficiency, acidity, salinity, low organic carbon risks with actionable advice (popup)
- **Soil test recommendation** — prioritized test list for the soil (popup)
- **Crop Care Assistant** — full tenure timeline (vegetative → flowering → fruiting → maturity) with day ranges and stage-wise tasks for irrigation, nutrients, weeding, and pest watch (popup)
- **Crop tenure aware** — dose adjusts for short (<120d), medium, and long (>200d) crops
- **Over-application guardrail** — "No Fertilizer Needed" when soil already meets crop needs
- **Trilingual UI** — English, हिन्दी, मराठी

## Tech Stack

- **Backend:** Python, Flask
- **ML:** scikit-learn RandomForestClassifier (300 trees)
- **Frontend:** HTML, CSS, vanilla JavaScript
- **Data:** rule-generated agronomy dataset (N-P-K deficit matching)

## Setup & Run

```bash
# 1. Clone the repo
git clone https://github.com/YOUR-USERNAME/fertilizer-app.git
cd fertilizer-app

# 2. Create and activate a virtual environment
python -m venv .venv
.venv\Scripts\activate        # Windows
source .venv/bin/activate     # Linux/macOS

# 3. Install dependencies
pip install -r requirements.txt

# 4. Regenerate the model (the .pkl is excluded from git)
python model\train_model.py

# 5. Run the app
python app.py
```

Open **http://127.0.0.1:5000** in your browser.

> Note: `model/fertilizer_model.pkl` is intentionally not committed (35 MB). It is regenerated by `train_model.py`. If `data/fertilizer_dataset.csv` is missing, run `python data\generate_dataset.py` first.

## API Endpoints

| Endpoint | Method | Description |
|---|---|---|
| `/` | GET | Web page |
| `/api/predict` | POST | Fertilizer recommendation, bags, price, combination, alternatives, alerts, balance |
| `/api/soil-advice?color=<name>` | GET | Suggested soil tests + baselines for a colour |
| `/api/care-plan` | POST | Crop tenure timeline with stage-wise tasks |
| `/api/options` | GET | Crop types + soil types from the model |

### Example: `/api/predict`

```json
POST /api/predict
{
  "temperature": 27,
  "soil_type": "red",
  "soil_color": "red",
  "crop_type": "groundnut",
  "land_area": 2,
  "crop_stage": "vegetative"
}
```

Response includes `recommendation`, `combination` (name/bags/per_bag/cost), `combo_total`, `alt` (alternatives), `alerts`, `soil_tests`, `ratings`, `estimated`, `tenure_days`.

## How the Recommendation Works

1. **Soil colour/type** → estimates N/P/K baseline and risk profile (acidity, salinity, Zn deficiency…)
2. **Crop + stage + tenure** → effective N/P/K dose (kg/acre) after soil availability and stage factors
3. **Combination** → primary P/K grade for the top pick, **Urea** for remaining N, **MOP** for remaining K
4. **Bags & cost** → 50 kg bags × land area → total bags and ₹ cost
5. **Advice popups** → soil tests, health alerts, and full tenure care plan

## Disclaimer

For demonstration and educational purposes. Nutrient estimates from soil colour are a pre-screen, not a substitute for a laboratory soil test.
